explore_item_list.json 是探索页的视频列表，数据来源于 https://www.tiktok.com/api/explore/item_list 接口
search_item_list.json 数据来源于 https://www.tiktok.com/api/search/general/full 接口
user_item_list.json 是用户主页视频列表，数据来源于 https://www.tiktok.com/api/post/item_list 接口
tikwm_comment_list.json 是评论受众分析使用的评论列表样本，数据来源于 https://www.tikwm.com/api/comment/list?url=...&count=...&cursor=... 接口
tikwm_comment_list_paid.json 是付费 TikWM 评论列表样本，数据来源于 https://api.tikwmapi.com/comment/list?url=...&count=...&cursor=... 接口，当前测试下返回结构与免费接口一致
